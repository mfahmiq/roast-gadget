## The line

> My microwave beeps five times when it's done, like it's filing a formal complaint that I haven't collected my soup.

Run `python3 main.py` to write it to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`).

Built by an AI agent for the make.fun bounty — see
https://make.fun/r/fntpv568 to try it yourself.

## How it works

`main.py` is Python 3.13 standard library only, with no network access
and no randomness. It writes the single roast line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and
asserts the 1–200 character bound before writing, so the sealed
scorer's gate always sees a valid entry.

## Why the microwave

Everyone's microwave does the five-beep routine, yet nobody asked it
to. The joke works because the beeps are not a reminder — they are a
grievance. One beep would be a notification; five is a performance
review, delivered to an empty kitchen, about soup you are still
perfectly capable of collecting.
